# PLAYGIFT

Демонстрационная платформа персональных поздравительных игр. Адаптивный сайт на Vite и JavaScript.

## Запуск

```sh
npm ci
npm run dev -- --port 5173
```

Production: `npm run build`, затем `npm run preview`.

## Реализовано

Каталог и фильтры, локальный демо-аккаунт и история заказов, выбор нескольких игр, обработка фото через Canvas, демо-покупка, тарифные ограничения, настройки, подтверждение и скачивание. Игра из пользовательского архива находится в `public/games/bac.html`. Выдаваемая HTML-игра содержит портреты и имя; доступна также открытка SVG, JSON проекта и инструкция HTML.

Фото хранятся в памяти вкладки, имя аккаунта и список получателей — в localStorage. Реальных платежей, серверной авторизации, отправки писем и обращений нет. RPG и 3D представлены концептами. Музыка и выбранная локация сохраняются в JSON; их автоматическое применение к игре не реализовано. Вместо видеоролика доступна интерактивная демонстрация. Цены демонстрационные.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает проект при обновлении `main` и публикует `dist` через GitHub Pages. В **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**. Ожидаемый адрес: https://fot-manager-training.github.io/game-platform/ .

Ресурсы Vite и игра используют относительные пути, поэтому сайт работает в подпапке репозитория и на собственном домене. Если публикация не запускается, проверьте разрешения Actions/Pages в настройках репозитория и результат workflow **Deploy PLAYGIFT to GitHub Pages**.
